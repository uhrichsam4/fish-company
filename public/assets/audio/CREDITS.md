## Regenerating / re-sourcing

- **Synthesized assets**: `python3 tools/gen_audio.py --out <dir>` (deterministic; reads no external data). See the module docstring for the DSP techniques used.
- **Kenney packs**: re-download from the pack pages listed above; extract the `Audio/` folder.
- **Freesound recordings**: re-fetch via the Openverse API (`https://api.openverse.org/v1/audio/?q=<query>&license=cc0,pdm`) or open the source URL directly.
- **Verify**: `node tools/check_audio_manifest.mjs` confirms every file the manifest (`src/data/audioManifest.js`) references exists on disk.
