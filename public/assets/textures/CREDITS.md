No CC0 water-normal or caustics source was good/seamless enough to justify
using over a controllable procedural version, per the sourcing brief; all six
are produced by `tools/gen_textures.py` using tileable Perlin fBm and
directional sine wave trains (see that file's docstring for the exact
technique — every periodic component is built so the image dimension is an
exact multiple of the pattern's period, so there is no visible seam).

## Processing

Every sourced material was resized with Pillow (`LANCZOS`) to 512x512 (1024x1024
for the hero ground materials: `sand`, `sand_wet`, `sand_seafloor`,
`wood_planks`, `wood_painted`) and re-saved as JPEG — quality 82 for
color/roughness, quality 90 for normal maps — discarding AO/displacement/
metalness maps entirely per the browser-budget brief. `sand_wet` is a local
darken/cool/roughness-reduce edit of the sourced `sand` color+roughness maps
(normal reused as-is). HDRI equirects were tone-mapped with OpenCV
(`cv2.imread` reads Radiance `.hdr` directly as linear float32) and resized
with `INTER_AREA`. None of this processing is redistribution of the original
full-resolution files.

## Reproducing

- `tools/gen_textures.py` — every procedural texture (water normals, foam,
  caustics, noise/perlin utility textures, the sand-seafloor ripple overlay,
  the fish-scales material, all ten particle sprites). Run directly:
  `python3 tools/gen_textures.py`. Requires `numpy` + `Pillow`.
- The ambientCG/Poly Haven download + resize pass and the HDRI tone-map pass
  were one-off build scripts (not checked into the repo) — re-run by
  downloading the asset ids/slugs listed above and resizing the same way
  (see "Processing").
